Privacy Policy

Last updated: 13 November 2026

Inkforge Uploader is a private desktop tool used only by the owner of the Inkforge YouTube channel.

What data is accessed

With the owner's permission (Google OAuth), the tool uses the YouTube Data API scopes youtube.upload and youtube to upload videos, set thumbnails and schedule publishing on the owner's own channel, and to read that channel's basic details.

How data is used and stored

The OAuth token is stored only on the owner's own computer. No Google user data is sold, shared with third parties, used for advertising, or sent to any server other than Google's APIs. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the token file on the computer removes all stored data.

YouTube's own terms apply: YouTube Terms of Service and Google Privacy Policy.
